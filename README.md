# Game Money Ledger

Frontend SPA for tracking internal game money ledger across multiple game types.
TFT is one supported game type, not the product name.

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui style components
- React Router
- TanStack Query
- React Hook Form + Zod
- Supabase client

## Scripts

```bash
npm run dev
npm run lint
npm run build
```

Copy `.env.example` to `.env.local` and fill Supabase values when the Supabase
project is ready.
